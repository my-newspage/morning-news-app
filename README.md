# 朝のニュース Webアプリ

Googleアカウント不要のニュースリーダー。毎朝、ファッション4件（靴2・小物1・服1）、金融市場2件、世界情勢2件、不動産3件を目安に収集します。ファッションはHOUYHNHNM、FASHIONSNAP、HYPEBEAST Japan、Masteredの記事から取得し、元記事の掲載画像がある場合のみ表示します。既読・お気に入り・前回の記事とスクロール位置は**同じ端末・同じブラウザー内**に保存します。

## 公開手順（GitHubアカウントは必要）
1. GitHubで新しい **Public** リポジトリ（例 `morning-news`）を作る。
2. このフォルダー内の `index.html`、`update_news.py`、`data/news.json`、`.github/workflows/update.yml` を**フォルダー構造ごと**アップロードする。
3. リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** を選ぶ。
4. **Actions → 朝のニュース自動更新 → Run workflow** で初回更新を実行する。
5. 数分後、`https://ユーザー名.github.io/morning-news/` にアクセスする。Android Chromeのメニューから「ホーム画面に追加」でアプリのように起動できる。

## 注意事項
- GitHub Actionsの定時実行は遅延することがあり、**9時ちょうどの反映は保証されません**。
- 金融市場・世界情勢・不動産はGoogle News RSSから見出しと概要を収集します。記事の内容、価格、発売日、在庫を個別に検証する仕組みではありません。ChatGPTが出典を確認して書く非公開Siteの記事とは品質が異なります。
- ファッションの画像は掲載元が配信する画像URLを表示します。元記事の画像が得られない場合は画像を表示しません。
- ユニクロ・GU感謝祭は2026年11月26日まで案内を表示し、終了後は表示しません。今後のセール情報の自動判定は対象外です。
- Google News RSSの取得制限、ニュース配信側の変更、GitHub Actionsの停止により更新できない場合があります。
- 既読情報はブラウザーのlocalStorageに保存します。別端末への同期やバックアップはありません。
- RSSの配信元へのリンクを表示します。記事本文の無断転載はしません。
- GitHub Pagesの公開リポジトリに保存する記事データは**公開情報**です。
- アーカイブは最大60日分です。

## 電車の運行表示
- 東横線と横浜線はYahoo!路線情報を約15分間隔で確認し、掲載された運行状態、説明、情報源の更新時刻を表示します。GitHub Actionsの起動は遅れる場合があります。
- JR東日本の運行情報も確認し、公式に横浜線の影響が掲載された場合は公式情報を優先します。東急公式と利用者投稿はリンク先で確認できます。投稿だけで遅延を確定表示しません。
- 画面の「更新」は取得済みデータの再読み込みです。取得できなかった場合や情報が古い場合はその旨を表示します。
